**Sistema de gestión de incidentes de ciberseguridad**
**Trabajo Fin de Grado — Ingeniería de Telecomunicaciones**

Universitat Oberta de Catalunya (UOC) · 2026

**📌 Descripción**

Este Trabajo Fin de Grado (TFG) tiene como objetivo principal el diseño de un sistema de gestión de incidentes de ciberseguridad escalable y adaptable a diferentes entornos corporativos, con independencia de su tamaño o sector.

La finalidad es proporcionar un marco metodológico que permita a las organizaciones desarrollar una capacidad de respuesta consistente frente a las ciberamenazas, priorizando la continuidad del negocio y la mitigación de riesgos.

El proyecto está contextualizado en un entorno empresarial caracterizado por un escenario de amenazas cada vez más complejas y se fundamenta en estándares y marcos de referencia ampliamente reconocidos:

ISO/IEC 27001
ISO/IEC 27035
NIST SP 800-61r3
Reglamento General de Protección de Datos (RGPD/GDPR)
Esquema Nacional de Seguridad (ENS)

**🔬 Metodología**

La metodología empleada se estructura en diferentes fases:

Investigación y análisis de las principales amenazas de ciberseguridad.
Estudio de buenas prácticas y estándares de referencia.
Diseño de un ciclo de vida para la gestión de incidentes.
Definición de roles y responsabilidades.
Desarrollo de documentación de apoyo.
Aplicación del modelo a un caso práctico en una organización ficticia.
Validación del sistema mediante la simulación de un incidente.

**📄 Documentación desarrollada**

Como parte del proyecto se desarrollan diferentes elementos de apoyo para la gestión de incidentes, entre ellos:

Matriz RACI de responsabilidades.
Matrices de criticidad.
Plantillas para la gestión y comunicación de incidentes.
Procedimientos de respuesta.
Métricas e indicadores KPI.
Documentación asociada al ciclo de vida del incidente.

**🏢 Caso práctico**

El modelo se aplica a una organización empresarial ficticia, utilizada para validar su funcionamiento mediante la simulación de un escenario de ciberseguridad.

El caso práctico permite analizar las diferentes fases de respuesta ante un incidente y comprobar la aplicación de los procedimientos, roles, responsabilidades y mecanismos de medición definidos.

**🎯 Resultados**

El proyecto culmina con la definición de un procedimiento integral de gestión de incidentes de ciberseguridad, acompañado de mecanismos para medir la capacidad de respuesta de la organización mediante indicadores de rendimiento.

La validación del modelo se realiza mediante la simulación de un incidente de seguridad, permitiendo evaluar su aplicación y obtener conclusiones orientadas a la mejora continua.
